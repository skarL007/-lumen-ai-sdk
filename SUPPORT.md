# Support

LumenAI is alpha software. The current supported development branch is `LumenAI`, and the latest published `0.x` release receives best-effort fixes.

## Where to Ask

- Bugs: open a GitHub issue with a minimal reproduction.
- Security vulnerabilities: use GitHub private security advisories, not public issues.
- Feature requests: open a GitHub issue and describe the use case, expected event shape, and target integration.

## Compatibility

LumenAI v0.2 targets Python 3.11 and 3.12. Public APIs can still evolve before v1.0, but changes should be documented in `CHANGELOG.md`.

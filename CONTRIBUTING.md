# Contributing to LumenAI 🔦

First off, thank you for considering contributing to LumenAI! It's people like you that make LumenAI such a great tool for the AI community.

## How Can I Contribute?

### 💸 Update Pricing Tables
The easiest way to help is by updating the `PRICING_TABLE` in `packages/lumen-ai-core/src/lumen_ai/schema/semconv.py` or contributing to our community JSON feed when new models are released.

### 🐛 Reporting Bugs
* Use the GitHub Issue Tracker.
* Describe the bug in detail and provide a minimal reproducible example if possible.

### 💡 Suggesting Enhancements
* Open an issue with the tag `enhancement`.
* Describe the use case and how it benefits the broader community.

### 🛠️ Pull Requests
1. Fork the repo and create your branch from `LumenAI`.
2. If you've added code that should be tested, add tests!
3. Ensure the test suite passes.
4. Open the PR!

## Style Guide
* We follow PEP 8 for Python code.
* Use descriptive commit messages.

# Security Policy 🛡️

## Supported Versions
Only the latest version of LumenAI is supported for security updates. We recommend all users to keep their SDK updated to the latest minor version.

## Reporting a Vulnerability
We take security seriously! If you discover a vulnerability, please do NOT open a public GitHub issue.

Please report it privately by:
*   Opening a [GitHub Security Advisory](https://github.com/skarL007/-lumen-ai-sdk/security/advisories/new) (preferred)
*   Describing the issue and steps to reproduce.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Our Commitment
LumenAI will never log, store, or export raw prompt/response content by default. Our focus is purely on token counts, costs, and metadata.
